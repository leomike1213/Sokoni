# Sokoni

Your shop, on WhatsApp. Sales page for a WhatsApp shop-building service for small Kenyan businesses.

Single static page (`index.html`). No build step, no dependencies.

## Go live with GitHub Pages
1. Create a repository (e.g. `sokoni`) and upload `index.html` and `README.md`.
2. Settings > Pages > Source: "Deploy from a branch", branch `main`, folder `/ (root)`, Save.
3. After 1 to 2 minutes your site is at `https://YOUR-USERNAME.github.io/sokoni/`.

## Change the WhatsApp number
Edit the `MY_NUMBER` line near the bottom of `index.html` (country code, no `+`, e.g. `254712345678`).
